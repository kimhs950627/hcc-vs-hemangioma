## 참고한 다른 자료 (이미지 미수집/부적합)

- Front Surg 2021;8:715429 "Malignant Tumors Misdiagnosed as Liver Hemangiomas" (pdfs/에 저장) — cone으로 US가 아닌 CT/MRI 위주 기술
- Cancers 2022;14:3997 "Current Imaging Diagnosis of HCC" — HCC의 약 25%가 hyperechoic이며 cirrhotic liver의 고에코 결절을 hemangioma로 오진하지 말라고 경고 (figure는 저에코 HCC 위주)
- Iran J Radiol (brieflands 79059) — 회색조/Doppler US로 혈관종 vs 악성 종양 감별 정확도 연구

## 주의사항

- 이 이미지들은 출판된 figure에서 추출한 것으로, 출판사 저작권의 적용을 받음. 연구 내부(외부 검증 프로토타입) 용도로는 fair use/학술 목적 범위로 볼 수 있으나, 논문이나 발표자료에 결과와 함께 게재하려면 출처 표기 및 라이선스(CC-BY 여부) 확인이 필요함. JCTH는 CC BY-NC 4.0임.
- 해상도가 출판 figure 수준으로 낮고, 장비/프리셋이 원 데이터셋과 다르므로 domain shift가 큼. 결과는 탐색적(exploratory) 외부 검증으로만 해석하는 것이 적절함.
- Hyperechoic HCC를 확인할 수 있는 공개 영상 데이터셋(예: 병원 데이터)이 확보되면 이 세트보다 우선할 것.

# UX 설계 — LiverDx

## 화면 구성
단일 Activity + 단일 스크롤 화면. 하단 네비게이션 없음 (기능 1개).

```
┌───────────────────────────────────────┐
│ LiverDx            모델 배지 ▸ 정보    │  상단 앱바 (고정)
├───────────────────────────────────────┤
│                                       │
│   [  이미지 슬롯  1:1 비율  ]          │  상태 1: 빈 상태
│      점선 테두리 + 안내문               │    "초음파 사진을 촬영하거나
│                                       │     갤러리에서 선택하세요"
│   [ 촬영 ] [ 갤러리 ] [ 초기화 ]        │
│                                       │
├───────────────────────────────────────┤
│   분석 중…  (진행 인디케이터)           │  상태 2: 로딩
├───────────────────────────────────────┤
│  ┌ Verdict ──────────────────────┐    │  상태 3: 결과
│  │ HCC (Malignant)      99.8 %   │    │  굵은 라벨 + 큰 퍼센트, 좌측 4dp 컬러 바
│  └───────────────────────────────┘    │
│  점수 4행                              │
│   Confidence      0.998  ▲cut 0.001   │
│   HCC Cosine      0.939  ▲cut -0.005  │
│   Hemangioma Cos. 0.044               │
│   Δscore          0.896  ▲cut -0.958  │
│                                       │
│  시각화 3 패널 (입력 프레임 / Attention / HCC map) │  탭하면 크게 보기
│                                       │
│  면책 문구 (고정, 작은 회색)            │
└───────────────────────────────────────┘
```

## 흐름
1. 빈 상태 → `촬영` → **CAMERA 런타임 권한 요청** → 앱 내 CameraX 화면(프리뷰 + 정사각 프레이밍
   가이드 + 라이트 토글 + 셔터). 촬영본은 캐시의 단일 파일로 저장된다.
   `갤러리`(PickVisualMedia)는 권한 없이 동작한다.
2. 이미지 도착 → EXIF 회전 보정 → 캐시 파일 즉시 삭제 → 사진 정리 파이프라인 → 리샘플 → 추론.
   단계는 하나로 합쳐져 있고 별도 "분석" 버튼은 없다.
3. 로딩 → 결과. 실패하면 결과 카드 자리에 **에러 카드** (메시지 + `다시 시도`).
4. 결과에서 패널 탭 → 전체화면 뷰어: RAW / CLEANED / ATTN / MAP 4개 레이어 +
   **불투명도 슬라이더**(0–100 %).
5. 정리 단계 토글을 바꾸면 **그 자리에서 재분석**한다 (재촬영 불필요).
6. `초기화` 버튼 또는 뒤로 가기 → 빈 상태로 복귀 (이전 결과·보정본·캐시 파일 폐기).

## 상태 정의
| 상태 | 화면 | 사용자 행동 |
|---|---|---|
| Idle | 점선 슬롯 + 3 버튼 | 촬영(권한) / 갤러리 |
| Capturing | 전체화면 프리뷰 + 가이드 + 셔터 + 라이트 | 촬영 / 닫기 |
| Analyzing | 슬롯에 썸네일 + 진행 인디케이터 + "INFERENCE RUNNING" | 뒤로(분석 폐기) |
| Success | Verdict + 4 점수행 + Photocleanup 패널 + 3 패널 | 단계 토글(재분석), 패널 확대, 초기화 |
| Error | 썸네일 + 에러 카드(원인 메시지) | 다시 시도 / 초기화 |

## 경계 조건
- 모델 자산 로딩 실패 → 앱 시작 시 에러 카드, 버튼 비활성.
- EXIF 1–8(회전·미러·transpose 포함) → `ExifInterface.rotationDegrees` + `isFlipped` 로 보정.
- 알파 채널 PNG → 알파는 버려지고 투명 영역이 검게 읽힘 (`cv2.imread` 와 동일 동작).
- 매우 큰 이미지 → `inSampleSize` 로 모델 입력의 2배까지 축소 후 디코드 (OOM 방지).
- 카메라 앱이 없는 기기 → 에러 카드(`카메라 앱을 찾을 수 없습니다`), 크래시 없음.
- 분석 중 다른 사진을 넣거나 초기화하면 이전 분석은 취소되고 결과를 덮어쓰지 않는다.
- 회전(가로↔세로) → `configChanges` 로 재구성 없이 유지. 프로세스 사망 후에도 촬영 URI 는 복원됨.
- 뒤로 가기: 뷰어 열림 → 뷰어 닫기; 결과/에러 있음 → Idle 로 복귀 (`BackHandler`, 그 외에는 앱 종료).
- 카메라 권한 거부 → 에러 카드(`카메라 권한이 거부되었습니다`), 갤러리는 계속 사용 가능.
- 촬영이 실패(카메라 준비 전 셔터, 저장 실패) → 에러 카드, 크래시 없음.
- 분석 중 단계 토글을 연타해도 이전 실행은 페어링된 세대 번호로 폐기되고 비트맵은 재활용된다.

## 사진 정리 패널
- 5개 단계 행(반사광 제거 · 조명 평탄화 · 그레이스케일 정렬 · 노이즈 제거 · 대비 정규화)에 각각
  Switch 1개. 행 오른쪽에 영문 stage id 를 작게 병기한다 (코드·툴 출력과 대조용).
- 헤더에 `실행 단계 수/전체 · glare %`.
- 그 아래 RESAMPLE 칩 2개 (BILINEAR + UINT8 / AREA AVERAGE)와 출처 한 줄.
- 스위치는 색만으로 상태를 나타내지 않는다(트랙 채움 + 손잡이 위치). 터치 타깃은 스위치 자체.

## 접근성
- 모든 터치 타깃 ≥ 48dp. 본문 대비 ≥ 4.5:1 (다크 배경 #0B0F14 위 #EAF1F8 ≈ 15:1).
- 점수는 색만으로 구분하지 않음: 값 위 라벨 텍스트 + 각 행 아래 `ABOVE/BELOW cutoff <값>` 문구와
  트랙 위 컷오프 눈금(`Caution` 색) 병기.
- 컬러맵 패널에는 색 구분용 램프 바와 `rollout, 4 layers` / `per-patch cosine, k=4` 캡션이 붙는다.
- 애니메이션은 진입 시 1회 스태거드 페이드/슬라이드만, 250 ms 이하.

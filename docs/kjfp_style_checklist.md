# KJFP 원고 작성 규정 — 체크리스트 (SSOT)

출처: 가정의학(KJFP) 투고규정 3. 원고 작성 방법 / 4. 원고의 제출. 저장일 2026-10-27.
판정 표기: `[M]` 기계 검증 가능 · `[H]` 사람이 판단. 체크박스는 제출 전 확인용.

## A. 연구설계 보고지침 `[H]`
- [ ] A1. 설계에 맞는 지침을 따랐는가 — RCT=CONSORT, 관찰연구=STROBE, 체계적고찰=PRISMA, **진단정확도=STARD**(본 연구는 진단정확도 → STARD)

## B. 원고 형식·조판 `[M]`
- [ ] B1. MS Word로 작성
- [ ] B2. **A4 (21 × 30 cm)**
- [ ] B3. **두 줄 간격**
- [ ] B4. 여백 상·하·좌·우 **3 cm**
- [ ] B5. 글자 크기 **10 pt 기준**
- [ ] B6. 글씨체 **바탕체**(국문) / Arial 또는 Times New Roman(영문)
- [ ] B7. 쪽번호: 표지 제외, **영문초록부터 하단 중앙**

## C. 용어·단위 `[M/H]`
- [ ] C1. 학술용어는 **대한의사협회 의학용어집**(term.kma.org) 기준
- [ ] C2. 약어는 최소한, 표준화된 약자만, **제목에 약어 금지**
- [ ] C3. 약어는 본문 첫 등장 시 명기 후 사용
- [ ] C4. 번역 곤란 용어·고유명사·단위·인명·지명은 원어, 필요 시 괄호 안 한자
- [ ] C5. 약품명은 일반명
- [ ] C6. 숫자는 아라비아 숫자
- [ ] C7. 측정 단위는 미터법 십배수, 온도 ℃, 혈압 mmHg, 검사치는 SI

## D. 원저 구성·분량 `[M]`
- [ ] D1. 순서: **①표지 ②영문초록+Keywords ③본문(서론·방법·결과·고찰) ④국문요약+중심단어 ⑤감사의 글(필요시) ⑥참고문헌 ⑦표 ⑧그림설명문**
- [ ] D2. 본문(표지·참고문헌·표·그림 제외) **10,000자(공백 포함) 이내**
- [ ] D3. **표+그림 합계 10개 이내**

### D-1. 표지
- [ ] D1a. 국문·영문 **제목**
- [ ] D1b. 국문·영문 **소제목(running title)** — 국문 공백 포함 **30자**, 영문 **10단어** 이내
- [ ] D1c. 모든 저자 성명, 소속 기관, **ORCID ID**
- [ ] D1d. 교신저자 정보(성명·소속주소·전화·팩스·e-mail·ORCID), 교신저자 `*` 위첨자
- [ ] D1e. **이해관계 관련 사항**(자문료·주식 등), **연구비 수혜내용**(표지 하단)
- [ ] D1f. 제목에 "무엇에 대한 연구/고찰" 표현 금지
- [ ] D1g. 저자 순서는 기여도 순, 영문은 `이름, 성`(음절별 첫 글자 대문자)

### D-2. 영문초록
- [ ] D2a. **250 단어 이내**, Structured: Background / Methods / Results / Conclusion
- [ ] D2b. 영문 중심단어 **4–6개**, 가능하면 **MeSH** 용어

### D-3. 본문
- [ ] D3a. 서론: 목적·중요성, 배경·원리 요약, 인용은 직접 관련만, **결과·결론 포함 금지**
- [ ] D3b. 방법: 계획·대상·방법 순서, 구체적으로. 대상 질병 확인 방법, 관찰자 주관 통제 방법, **IRB 승인 명시**, 기자재·시약은 (제품명, 제조사, 도시, 국가), 새 방법은 참고문헌과 간단 소개, **sex/gender 용어 명확화**(한 성별만 포함 시 이유), **통계 방법 상세**, **통계 프로그램 명시**, 결과는 정량화 + 불확실성(CI), **P 값은 대문자 P**
- [ ] D3c. 결과: 명료·논리적 나열, 표·그림 수치를 본문에 중복 나열 금지
- [ ] D3d. 고찰: 해석·타 자료 연관, 새 관찰 강조, 결과 중복 금지, 적용 범위·한계·향후 활용, 가설과 확인 방안

### D-4. 국문요약
- [ ] D4a. **1,000자 이내**, ①연구배경 ②방법 ③결과 ④결론 순
- [ ] D4b. 국문 중심단어 **4–6개**

### D-5. 감사의 글
- [ ] D5. 필요 시, 기여자 역할 명백히, **당사자 허가 후** 기재

## E. 참고문헌 `[M/H]`
- [ ] E1. **영문 작성**
- [ ] E2. 원저는 **30개 이하**
- [ ] E3. **본문 인용 순서대로** 아라비아 숫자
- [ ] E4. 저자 **6인 이하 전부 나열, 7인 이상은 6인까지 + et al**
- [ ] E5. 국문 문헌은 문헌에 표기된 영문으로
- [ ] E6. 저널명: 영문은 NLM 기준, 국문은 Korean Medical Journal Information 기준
- [ ] E7. 초록 인용 금지(불가피하면 밝힘), 미출간 채택은 `In press`, 미결정 원고는 `Unpublished observation` + 허가
- [ ] E8. **본문 표기**: 해당 내용 뒤 **위첨자 + 우측괄호**, 여러 개는 쉼표, **3개 이상 연속은 하이픈**
- [ ] E9. 위첨자 위치: 저자명 인용 시 이름 뒤, 아니면 문장 마지막 단어 뒤. 조사는 첨자 뒤, 쉼표·마침표는 첨자 앞. 저자 3명 이상은 `등` 뒤에 첨자
- [ ] E10. 형식(학술지): `저자. 제목. 잡지명 연도; 권: 시작면-종료면.` — 예: `J Korean Acad Fam Med 2007; 28: 599-603.`
- [ ] E11. 형식(단행본): `저자. 책제목. 판. 출판지: 출판사; 연도. p. 시작-종료.`
- [ ] E12. 형식(학술대회): 회보명/학회명, 개최 년월일, 개최지, 출판지, 출판사, 연도
- [ ] E13. 형식(학위논문): `저자. 제목[dissertation]. 도시: 대학; 연도. 언어.`
- [ ] E14. 형식(웹): `저자. 제목[Internet]. 출판지: 출판사; 갱신연도 [cited 연월일]. Available from: URL.`
- [ ] E15. 참고문헌 관리 소프트웨어 사용 가능

## F. 표 `[M]`
- [ ] F1. 제목·내용 **모두 영문**
- [ ] F2. 제목은 표 **상단**, **좌측 정렬**
- [ ] F3. 본문 인용 순서대로 번호, `Table` + 한 칸 + 숫자 + **마침표**
- [ ] F4. 제목 첫 단어 첫 글자 대문자, **끝에 마침표 없음**
- [ ] F5. 본문 표기는 `(Table 번호)`
- [ ] F6. 두 줄 간격, **한 면에 표 하나**
- [ ] F7. **내부 가로줄·세로줄 없음**(3선형)
- [ ] F8. 약어·설명은 하단 주석 필수, 해당 위치에 **알파벳 소문자 위첨자(a, b, c)**, 주석은 각단 정렬, 주석 첫 단어 대문자
- [ ] F9. 단위는 표 내부에 표기, 불필요한 대문자 금지
- [ ] F10. 평균·표준편차·대상수 제시, 주석에 통계기법, 비율은 반응 수+비율, 상관계수는 값 제시
- [ ] F11. 타인 표는 저작권 허락 + 각주 명시

## G. 그림·사진·설명문 `[M/H]`
- [ ] G1. 그림·설명문 **모두 영문**
- [ ] G2. 파일형식 **TIF/TIFF, JPEG, PPT** + **600 dpi 이상**, 별도 제출
- [ ] G3. 막대·꺾은선에 평균/비율, SD·SE 크기 표시, **P 값 필수**
- [ ] G4. 설명문에 **적용 통계검정** 기재
- [ ] G5. 제목 첫 단어 대문자, **끝에 마침표**
- [ ] G6. `Figure` + 한 칸 + 숫자 + 마침표, 본문 인용 순서대로
- [ ] G7. 본문 표기는 `(Figure 번호)`
- [ ] G8. 한 번호에 여러 장이면 **Figure 1A, Figure 2B** 형식
- [ ] G9. 타인 그림은 저작권 허락 + 설명문에 명시

## H. 기타 원고 유형(해당 시)
- [ ] H1. 종설·특별기고: 영문초록 비정형 250단어, 본문 서론·본론·결론
- [ ] H2. 증례: 본문 2,500자 이내, 참고문헌 10개 이하, 영문초록 비정형 250단어
- [ ] H3. Brief communication: 5,000자 이내, 표·그림 합계 2개 이하

## I. 제출 절차 `[H]`
- [ ] I1. 온라인 투고 시스템(kjfp.or.kr/submission)으로 제출
- [ ] I2. 저자 점검 Checklist 검토
- [ ] I3. **저작권 양도 동의서** 전 저자 서명 후 업로드
- [ ] I4. 수정 요청 시 **8주 이내** 재접수 + 저자 답변서(항목별)

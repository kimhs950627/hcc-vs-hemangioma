딥러닝 기초 ①

임베딩 — 영상을 구면(unit sphere) 위의 벡터로 옮긴다

  • 인코더가 영상을 고차원 벡터로 변환 → 방향(direction)이 의미를 담음
  • 벡터를 정규화하면 모두 반지름 1인 구면 위에 놓인다
  • 두 벡터의 각도 θ의 코사인 = cosine similarity (내적)

클래스별 대표 벡터(prototype, 훈련 세트 평균)를 구면에 두면 — 병변이 각 prototype에 얼마나 닮았는지가 연속값으로 나온다.

HCC cosine score = cos∠(z, HCC proto) · Δscore = HCC 닮음 − 혈관종 닮음

대상 및 방법 ② · 학습 전략

CE + SupCon, 2 backbone × 3 학습 모드 = 6개 조건 ablation

CE only

교차 엔트로피로 분류 경계만 형성. 임베딩 구조는 학습 목적이 아님.

CE + SupCon

같은 클래스는 가까이, 다른 클래스는 멀리 → 임베딩 응집·분리.

NNCLR 2단계

SSL(NNCLR) 사전학습 → CE+SupCon 미세조정. 사전학습의 추가 이득 검증.

총 손실 = 분류 손실 + 유사도 정렬 손실 (SupCon)

$$\mathcal{L} \;=\; \mathcal{L}_{\mathrm{CE}} \;+\; \lambda\,\mathcal{L}_{\mathrm{SupCon}},\qquad \mathcal{L}_{\mathrm{SupCon}}=\sum_{i}\frac{-1}{|P(i)|}\sum_{p\in P(i)}\log\frac{\exp(\mathbf{z}_i\!\cdot\!\mathbf{z}_p/\tau)}{\sum_{a\in A(i)}\exp(\mathbf{z}_i\!\cdot\!\mathbf{z}_a/\tau)}$$

384×384 입력 · AdamW · Cosine Annealing. 임계값은 검증 세트에서만 Youden's J로 결정 후 테스트 세트에 고정. 통계: DeLong[15], 영상 단위 95% CI, 대응 t·Wilcoxon·Pitman-Morgan 검정.

대상 및 방법 ③ · 이중 출력 정의

세 가지 출력의 의미

①

Confidence score

HCC 클래스 softmax 값(0–1). 확률이 아닌 결정 강도(decision strength)

②

HCC / Hemangioma cosine

병변 임베딩과 훈련 세트 mean prototype 간 cosine 유사도 = 전형성에 대한 닮음

③

Δscore

HCC cosine − Hemangioma cosine = 두 클래스 간 상대적 위치

주 분석은 mean prototype(n=1)이며, 클래스별 다중 subtype을 고려한 k-means prototype(k=4)는 민감도 분석으로 병행하였다. 모든 prototype은 훈련 세트에서만 산출하여 데이터 누출을 방지하였다.

Guo 2017 [11] · Khosla 2020 [12] · DeLong 1988 [15]

탐색적 의의와 남은 과제

의미 (Exploratory)

  • 출력 해석론의 전환 — softmax를 확률이 아닌 결정 강도로 재정의
  • 유사성 기반 추론 정량화 — HCC cosine·Δscore 표지자 후보 제시(임상 이득은 미입증)
  • SupCon의 추가적 정규화 가능성 — 임베딩 응집·분산 축소

한계

  • 단일기관·후향적 — 외부 검증 부재
  • 배경 간질환(간경변·지방간·AFP) 정보 부재
  • 영상 단위 CI — 환자 내 상관성 미보정(1:1 매칭 아님)
  • 참조표준 비대칭(HCC 병리 vs 혈관종 영상), spectrum bias
  • AUROC 1.000 천장효과 — 이득 구분 불가

본 연구는 B-mode 초음파에서 confidence score와 임베딩 기반 유사도 표지자(HCC cosine, Δscore)를 함께 산출하는 이중 출력 체계의 산출 가능성을 제시한 탐색적 연구이다. 실제 임상적 유용성은 다기관 외부 검증과 판독자 연구로 추가 평가되어야 한다.

모두 간암(HCC) — 혈관종처럼 보이지만 실제로는 HCC

혈관종의 전형은 고에코·경계 명확·후방음영 증가다. 그러나 HCC의 10–15%는 비전형 소견이고 고분화 HCC가 고에코 혈관종 패턴을 모사할 수 있다 [5]. 반대로 비전형 혈관종은 악성을 모사한다 [6,7].

임상 배경 ①2 / 14
임상 배경 ② · 연구 범위

이미 발견된 국소 병변에서 — HCC인가, 혈관종인가

1. 범위를 좁혀 둔다

이 연구는 간암 감시(surveillance)나 선별 검사가 아니다. 초음파에서 이미 발견된 국소 병변을 HCC와 혈관종으로 가르는 감별 진단 보조를 다룬다. 감시 민감도 향상은 주장하지 않는다.

"감시 민감도 47%"는 배경 설명이며 이 연구의 성능 근거가 아니다

2. B-mode 단독은 부족하다

경력 15년 판독자 236명의 B-mode 단독 판독 — 정확도 76.0% · 민감도 76.1% · 특이도 76.9%

비조영 US 딥러닝 meta-analysis: 민감도 81.7% · 특이도 84.8% → 개선 여지가 남아 있다

3. 두 클래스 안쪽이 넓다

HCC·혈관종 모두 전형–비전형 스펙트럼을 가진다. 기존 AI는 이 스펙트럼을 단일 이진 출력으로 압축해, 병변이 전형 군집의 핵심부인지 주변부인지를 알려주지 않는다.

판독자는 "전형 HCC와 얼마나 닮았는가"로 판단한다 — LI-RADS 계층 구조가 그 예

그래서 우리는 분류 성능이 아니라, 판독자가 이미 하는 "닮음" 판단을 숫자로 남기는 지표를 만들고 그 방법론적 타당성만 평가한다.

Minami 2023 [5] · Chou 2017 [6] · Sirli 2015 [7] · Yang 2020 [9] · Campello 2023 [18]

방법 ①4 / 14
방법 ② · 우리가 내는 것

확률 하나가 아니라 — "전형 소견과 얼마나 닮았는가"

① Confidence

HCC 클래스의 softmax 값. 보정된 사후확률이 아니므로 이 연구에서는 확률이 아니라 결정 강도로 부른다.

② HCC cosine

훈련 세트 HCC 임베딩의 평균 위치(prototype)와 병변 임베딩의 각도(cosine). "전형 HCC와 얼마나 닮았는가". k-means(k=4) 다중 prototype은 보완 민감도 분석.

③ Δscore

HCC cosine − 혈관종 cosine. 두 클래스 중 어느 쪽에 더 가까운가만 말하는 상대 위치 지표다. 이 지표의 검증 결과는 슬라이드 10에서 정직하게 다룬다.

판독자가 전형 소견과 비교하며 위험도를 나누는 사고(LI-RADS 계층)와 구조적으로 대응한다고 본다 — 임상적 유용성을 주장하는 근거는 아니다.

인코더 내부 — 필터가 훑고, CLS가 패치를 본다

흐름: 384×384×3 → CNN 특징 7×7×1280 → 패치 토큰 49개 → CLS 384차원. 세 지표는 모두 이 CLS 임베딩 하나에서 나온다. EfficientNetV2B0(7.1M)를 쓴 이유는 ResNet50V2(23.6M)와 동등한 AUROC를 더 가벼운 모델로 냈기 때문이다.

한계 — 임상 적용 전에 넘어야 할 것

  • 참조표준 비대칭: HCC는 병리확진, 혈관종은 영상 판독 → 혈관종 라벨 오류 가능
  • 선택 편향: 원저의 대표영상 선별 + 정제된 clean subset → 높은 정확도가 데이터 조건에서 기인했을 수 있음
  • 단일기관·단일 데이터셋 → 일반화·배포 주장을 하지 않는다. 장비 게인·탐촉자·검사자 변동 미평가
  • 환자 ID 없음 → 환자 단위 집계·cluster bootstrap 불가, CI는 image-level이라 좁게 추정됐을 수 있고, 근접 중복 프레임 감사도 불가
  • 배경 간 층화 미시행(B/C형 간염·간경변·지방간 정보 없음) → 모델이 배경 간 실질을 shortcut으로 학습했을 가능성을 배제할 수 없다
  • Grad-CAM 미제시: 배경 간 라벨이 없어 heatmap의 국소병변/배경 반응을 구분할 수 없어 오히려 오용 위험이 크다
  • 천장효과: 출력 간 우열 구분 불가 · Δscore는 SupCon에서 감소 → Δscore 타당성 지지 근거 없음
  • 미수행: AFP 대비 증분 기여, decision curve analysis(net benefit), 부트스트랩 CI, SSL 하이퍼파라미터 민감도

정리: 이 연구는 "이런 지표를 산출할 수 있다"는 방법론적 실현과 정직한 음성 결과를 보고한 탐색적 연구다. 임상적 유용성은 다기관 외부 검증과 판독자 대상 연구로만 판단될 수 있다.

말하는 것과, 말하지 않는 것

말하는 것

  • 같은 모델 하나에서 confidence와 임베딩 유사도(HCC cosine·Δscore)를 동시에 산출하는 방법을 구현했다
  • SupCon 학습이 HCC cosine 분포를 전형 HCC 쪽으로 정렬한다 (p<0.001)
  • 공개 데이터로 모든 수치를 재현 가능하게 산출했다
  • 증분 이득이 없다는 결과를 포함해 정직하게 보고했다

말하지 않는 것

  • 분류 성능이 우월하다 — 세 출력 AUROC가 같은 천장이라 비교 자체가 불가
  • 감시·선별에 쓰일 수 있다 — 범위는 이미 발견된 병변의 감별 보조
  • 일반화·즉시 적용 가능 — 단일기관, 외부 검증 없음
  • 임상적 이득·순편익 — decision curve analysis도 하지 않았다
  • Δscore의 임상적 타당성 — SupCon에서 오히려 감소했다

다음 단계는 이 순서다: ① 다기관·타 장비 외부 검증 → ② 조영증강 CT/MRI·CEUS 및 AFP와의 비교 → ③ 판독자 대상 전향적 비교로 실제 판단 변화와 환자 결과 확인 → ④ decision curve analysis로 순편익 평가.

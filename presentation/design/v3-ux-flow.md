## 독자 동선
1. **호기심**(2장: 이게 다 암이다) → 2. **필요**(2장 하단 76%) → 3. **해법**(3~5장) →
4. **검증**(6~8장) → 5. **한계**(9~10장) → 6. **마무리**(11장).
- 밀도 리듬: 텅 빔 → 꽉 → 중 → 꽉 → 중 → 꽉 → 꽉 → 중 → **텅 빔** → 중 → 텅 빔.
  같은 밀도가 3장 연속 오지 않게 배치되어 있다(6·7장은 표/도표라 성격이 다르다).

## 화면 규칙
- **상단 고정 존**: eyebrow(13px, 대문자 자간) → 제목 → 1px 헤어라인. 제목존 높이를 전 슬라이드 동일하게.
- **좌측 정렬 단일 축**: 모든 텍스트는 좌측 기준선을 공유한다. 가운데 정렬은 표지·마지막 장만.
- **하단 고정 존**: 좌측 섹션명, 우측 페이지 번호, 위에 헤어라인.
- 넘김: `fade`. 슬라이드 전환에 시선을 뺏지 않는다.
- 애니메이션은 콘텐츠가 있는 4장에서만 반복 재생. 나머지는 정지.

## 상태
- 인쇄(print-pdf): 애니메이션 대표 프레임 고정, 컨트롤·진행바 숨김, 배경지 제거.
- fragment(2장의 "모두 간암" 공개): 인쇄 시 항상 보이게.

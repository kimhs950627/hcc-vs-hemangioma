# 비주얼 디렉션 — v3 "학술지 판면"

## 톤
학술지 원저의 판면을 슬라이드로 옮긴다. 종이 위에 인쇄된 느낌 — 색은 억제하고, 위계는 **크기와 여백**으로 만든다.
"발표용 템플릿"이 아니라 "저널 한 페이지를 크게 띄운 것"에 가깝게.

## 팔레트 (역할 고정, 컴포넌트에 hex 하드코딩 금지)

| 토큰 | 값 | 역할 |
|---|---|---|
| `--paper` | `#FAF9F5` | 배경(웜 오프화이트). 순수 흰색 금지 |
| `--paper-2` | `#F3F1EA` | 보조 블록 바탕 |
| `--ink` | `#16202A` | 본문·제목(쿨 네이비 블랙). 순수 검정 금지 |
| `--ink-soft` | `#3A4750` | 보조 텍스트 |
| `--muted` | `#5A666F` | 각주·라벨 |
| `--line` | `#D9D5C9` | 헤어라인 |
| `--accent` | `#0F6E63` | **구조 악센트 하나** — eyebrow, 규칙선, 강조 |
| `--hcc` | `#9E3B2F` | 의미색: HCC |
| `--hem` | `#2A6076` | 의미색: 혈관종 |
| `--caution` | `#8A6A2A` | 의미색: 한계·감소 경고 (2장에서만) |

> 색이 4계열인 이유: 악센트 1개 + **데이터 의미색 2개**(HCC/혈관종) + 경고 1개.
> 장식으로 쓰이는 색은 악센트 하나뿐이다.

## 타이포 (캔버스 1280×720 기준 px)

| 역할 | 폰트 | 크기 | 비고 |
|---|---|---|---|
| 표지 제목 | Batang(세리프) | 62px | 자간 −0.02em |
| 슬라이드 주장(`claim`) | Batang | 42px | 굵기 700, 행간 1.3 |
| 슬라이드 제목(`title`) | Batang | 40px | 아래 1px 규칙선 |
| 본문·불릿 | Malgun Gothic | 25px | 행간 1.55 |
| 보조·라벨 | Malgun Gothic | 21px | `--muted` |
| 각주 | Malgun Gothic | 18px | 최소 허용치 |
| 수치(`stat`) | Batang | 54px | `tabular-nums` |
| eyebrow | Malgun Gothic | 13px | 대문자, 자간 .18em, `--accent` |

세리프는 **제목·수치**에만. 본문은 산세리프. 같은 계열의 굵기 차이로 위계를 만들지 않는다.

## 그리드·여백
- 좌우 `64px`, 상단 `52px`, 하단 `44px`. 콘텐츠 폭 1152px.
- 상단 존(eyebrow → 제목 → 헤어라인) 높이를 **전 슬라이드 동일**하게 고정.
- 하단 존(섹션명 · 페이지)도 고정. 본문은 그 사이에서 세로 중앙.
- 8px 배수만 사용. 12/16/24/40/64.

## 표면
- 그림자 없음. 둥근 모서리 없음(`--radius: 2px`). 1px 헤어라인으로만 구분.
- 카드 대신 **블록**: `--paper-2` 바탕 + 좌측 2px 악센트 규칙. 테두리 최소화.
- 배경 깊이: `feTurbulence` 종이 그레인 2.5% (화면 전용, 인쇄에서는 제거).
- 표: 머리행만 `--paper-2`, 세로줄 없음, 숫자 우측 정렬 + `tabular-nums`.

## 모션
- 슬라이드 전환 `fade` (slide 아님). 기본 속도.
- 반복 애니메이션 4개는 콘텐츠 — 그대로 유지.
- 마이크로 인터랙션 없음. `transition: all` 금지.
- `prefers-reduced-motion: reduce` → 애니메이션을 대표 프레임에서 정지.

## 금지 목록
보라/인디고, `#0056b3` 기본 파랑, Inter/Roboto/system-ui, radius 8px + 그림자 카드 반복,
균등 3~4카드, 이모지 아이콘, 그라디언트 버튼, 가운데 정렬 남발(표지·마지막 장 제외).
